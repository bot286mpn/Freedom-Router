# Инструкция по сборке SecureProxy.exe

Этот документ предназначен для тех, кто хочет собрать автономный EXE-файл приложения.

## 📋 Что вы получите

После сборки у вас будет **один файл** `SecureProxy.exe` размером ~35-45 MB, который:
- ✅ Работает без установки Python
- ✅ Автоматически скачивает Tor и X-Ray при первом запуске
- ✅ Не требует дополнительных файлов
- ✅ Можно передавать другим пользователям

## 🔧 Требования для сборки

### Обязательные:
- **Операционная система:** Windows 10 или Windows 11
- **Python:** версия 3.8 или выше

### Как установить Python:

1. Перейдите на https://www.python.org/downloads/
2. Скачайте последнюю версию для Windows
3. **ВАЖНО:** При установке отметьте галочку ✅ **"Add Python to PATH"**
4. Нажмите "Install Now"
5. После установки перезапустите терминал/командную строку

### Проверка установки:

Откройте командную строку (Win+R → cmd) и введите:
```bash
python --version
```

Должно отобразиться что-то вроде: `Python 3.11.5`

## 🚀 Пошаговая инструкция сборки

### Шаг 1: Подготовка

1. Скачайте исходный код проекта
2. Распакуйте в любую папку (например, `C:\Projects\SecureProxy`)
3. Убедитесь, что в папке есть файл `build.bat`

### Шаг 2: Запуск сборщика

1. Откройте папку с проектом
2. **Дважды кликните** по файлу `build.bat`
3. Откроется черное окно терминала

### Шаг 3: Ожидание

Сборщик автоматически выполнит следующие действия:

```
[ШАГ 1/3] Установка инструментов сборки...
→ Установит: pyinstaller, packaging, requests и другие

[ШАГ 2/3] Очистка временных файлов...
→ Удалит старые сборки (если есть)

[ШАГ 3/3] Компиляция SecureProxy.exe...
→ Создаст автономный EXE-файл (3-5 минут)
```

**Не закрывайте окно** до завершения процесса!

### Шаг 4: Готовый файл

После успешной сборки:
1. Автоматически откроется папка `dist`
2. В ней будет файл `SecureProxy.exe`
3. Также там будет `HOW_TO_USE.txt` с инструкцией для пользователей

## ⚠️ Возможные проблемы и решения

### Ошибка: "Python не найден"

**Решение:**
1. Установите Python с https://www.python.org/downloads/
2. Обязательно отметьте галочку "Add Python to PATH"
3. Перезапустите терминал
4. Попробуйте снова

### Ошибка: "Не удалось установить зависимости"

**Причина:** Проблемы с подключением к интернету или блокировки

**Решение:**
1. Проверьте подключение к интернету
2. Попробуйте использовать мобильную точку доступа
3. Если не помогает — установите вручную:
   ```bash
   pip install pyinstaller packaging requests urllib3 chardet idna certifi
   ```
4. Запустите `build.bat` снова

### Ошибка при компиляции

**Причина:** Конфликт версий или поврежденные файлы

**Решение:**
1. Удалите папки `build`, `dist` и файл `SecureProxy.spec`
2. Обновите pip: `python -m pip install --upgrade pip`
3. Переустановите PyInstaller: 
   ```bash
   pip uninstall pyinstaller
   pip install pyinstaller
   ```
4. Запустите `build.bat` снова

### Антивирус удаляет EXE файл

**Причина:** Ложное срабатывание на упакованные PyInstaller файлы

**Решение:**
1. Добавьте папку с приложением в исключения антивируса
2. Или временно отключите антивирус при сборке
3. Файл безопасен — это ложное срабатывание

### Размер файла слишком большой (>100 MB)

**Причина:** В сборку попали лишние библиотеки

**Решение:**
1. Удалите папку `build` и попробуйте снова
2. Убедитесь, что используете свежую версию PyInstaller
3. Проверьте, что не установлены лишние пакеты Python

## 📊 Технические детали

### Что внутри EXE файла:

```
SecureProxy.exe содержит:
├── main.py (основной код)
├── core/ (ядро приложения)
│   ├── dependency_manager.py
│   ├── tor_manager.py
│   ├── xray_manager.py
│   └── proxy_manager.py
├── gui/ (интерфейс)
│   └── main_window.py
├── Python 3.x (встроенный интерпретатор)
└── Все необходимые библиотеки
```

### Папки создаваемые при работе:

При первом запуске приложение создаст:
```
SecureProxy.exe
├── bin/           # Tor и X-Ray (скачиваются автоматически)
├── configs/       # Конфигурации пользователя
├── logs/          # Логи работы
└── data/          # Другие данные
```
