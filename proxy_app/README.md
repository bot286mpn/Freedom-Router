# SecureProxy - Универсальный прокси-клиент для Windows

Приложение для обхода блокировок с поддержкой Tor, X-Ray (VMess, VLESS, Trojan, Shadowsocks, Reality) и других современных протоколов.

## 🚀 Быстрый старт для пользователей

### Вариант 1: Готовый EXE-файл (рекомендуется)

Если у вас уже есть файл `SecureProxy.exe`:

1. **Просто запустите** `SecureProxy.exe` двойным кликом
2. При первом запуске приложение **автоматически скачает** необходимые компоненты (Tor и X-Ray)
3. Нажмите **"Скачать автоматически"** и дождитесь завершения
4. Если загрузка не удалась из-за блокировок - следуйте инструкциям в приложении для ручной установки
5. Готово! Можно добавлять конфигурации и подключаться

**Важно:** Пользователю НЕ НУЖНО устанавливать Python или другие зависимости!

### Вариант 2: Сборка из исходного кода

Если у вас есть исходный код приложения:

#### Требования для сборки:
- Windows 10/11
- Python 3.8 или выше (скачать с [python.org](https://www.python.org/downloads/))
- **ВАЖНО:** При установке Python отметьте галочку **"Add Python to PATH"**

#### Инструкция по сборке:

1. **Скачайте проект** на компьютер
   
2. **Запустите сборщик:**
   - Откройте папку с проектом
   - Дважды кликните по файлу `build.bat`
   - Дождитесь завершения процесса (3-5 минут)

3. **Найдите готовый файл:**
   - После успешной сборки откроется папка `dist`
   - В ней будет файл `SecureProxy.exe` (~35-45 MB)
   - Также там будет инструкция `HOW_TO_USE.txt`

4. **Распространение:**
   - Скопируйте `SecureProxy.exe` в любое место
   - Передайте пользователям - им не нужен Python!

## 🔧 Возможности приложения

### Поддерживаемые протоколы:
- **Tor Network** - анонимное соединение через сеть Tor
- **X-Ray Core** с протоколами:
  - VMess / VMessAEAD
  - VLESS (включая Reality)
  - Trojan
  - Shadowsocks
  - SOCKS / HTTP
- **Прокси-серверы** - поддержка пользовательских SOCKS5/HTTP прокси

### Функции:
- ✅ **Автоматическая загрузка зависимостей** - Tor и X-Ray скачиваются при первом запуске
- ✅ **Проверка обновлений** - отслеживание актуальных версий компонентов
- ✅ **Локальный SOCKS5 прокси** - порт 10808 для использования в других приложениях
- ✅ **Системный прокси** - автоматическая настройка прокси для всей системы Windows
- ✅ **Проксирование приложений** - выбор конкретных программ для работы через прокси
- ✅ **Импорт конфигураций** - добавление серверов из буфера обмена (ссылки vmess://, vless:// и т.д.)
- ✅ **Избранные серверы** - быстрое переключение между конфигурациями
- ✅ **Статистика подключения** - мониторинг трафика и задержек
- ✅ **Обход блокировок** - интеллектуальный выбор протоколов для обхода ограничений

## 🛠 Для разработчиков

### Запуск из исходного кода:

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
python main.py
```

### Сборка EXE вручную:

```bash

pip install pyinstaller packaging requests

# Сборка
pyinstaller --onefile --windowed --name "SecureProxy" --clean main.py
```

### Добавление новых протоколов:

1. Создайте новый менеджер в папке `core/`
2. Реализуйте интерфейс базового менеджера
3. Добавьте интеграцию в `main_window.py`

## ❓ Частые вопросы

### Q: Приложение не может скачать Tor/X-Ray
**A:** Это происходит из-за блокировок. Решение:
1. Попробуйте использовать другой интернет (мобильная точка доступа)
2. Скачайте вручную по ссылкам из приложения
3. Распакуйте в папку `bin/` рядом с приложением

### Q: Антивирус ругается на EXE файл
**A:** Ложное срабатывание из-за упаковки PyInstaller. Решения:
1. Добавьте в исключения антивируса
2. Соберите самостоятельно из исходного кода
3. Используйте portable-версию без установки

### Q: Как обновить приложение?
**A:** 
1. Скачайте новую версию `SecureProxy.exe`
2. Замените старый файл
3. Конфигурации сохранятся в папке `configs/`

### Q: Где хранятся настройки?
**A:** В папке `configs/` рядом с приложением. Можно переносить вместе с EXE файлом.
