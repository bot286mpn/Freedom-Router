# SecureProxy - Универсальный прокси клиент

Приложение для обхода блокировок с поддержкой Tor, X-Ray/V2Ray и современных протоколов.

## Возможности

### Поддерживаемые протоколы:
- **Tor Network** - анонимная сеть через Tor Expert Bundle
- **VMess** - оригинальный протокол V2Ray
- **VLESS** - легкий протокол нового поколения
- **Trojan** - маскировка под HTTPS трафик
- **Shadowsocks** - быстрый зашифрованный прокси
- **Reality** - современная защита от обнаружения

### Функции:
- ✅ Локальный SOCKS5 прокси сервер (порт 10808)
- ✅ HTTP прокси (порт 10809)
- ✅ Системный прокси (автоматическая настройка Windows)
- ✅ Проксирование отдельных приложений
- ✅ Импорт конфигураций из буфера обмена
- ✅ Поддержка ссылок: vmess://, vless://, trojan://, ss://
- ✅ Современный темный интерфейс
- ✅ Журнал событий
- ✅ Проверка соединения
- ✅ **Автоматическая загрузка и обновление зависимостей** (Tor и X-Ray)
- ✅ **Проверка доступности компонентов при запуске**
- ✅ **Ручная установка при недоступности источников**

## Установка

### Требования:
- Windows 10/11
- Python 3.8 или выше

### Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 2: Скачивание дополнительных компонентов

#### 🔹 Автоматическая установка (рекомендуется):

При первом запуске приложение автоматически:
1. Проверит наличие Tor и X-Ray
2. Предложит скачать отсутствующие компоненты
3. Загрузит последние версии с официальных источников
4. Установит их в папку `bin/`

Если автоматическая загрузка не удалась (из-за блокировок), 
приложение предоставит подробные инструкции по ручной установке.

#### 🔹 Ручная установка:

##### Tor Expert Bundle:
1. Перейдите на https://www.torproject.org/download/
2. Скачайте "Tor Expert Bundle" для Windows
3. Распакуйте в папку приложения: `proxy_app/bin/Tor/`
4. Убедитесь, что файл находится в: `proxy_app/bin/Tor/tor.exe`

##### X-Ray Core:
1. Перейдите на https://github.com/XTLS/Xray-core/releases
2. Скачайте последнюю версию для Windows (`Xray-windows-64.zip`)
3. Распакуйте в папку приложения: `proxy_app/bin/Xray/`
4. Убедитесь, что файл находится в: `proxy_app/bin/Xray/xray.exe`

**Или** укажите пути к исполняемым файлам в настройках приложения.

### Шаг 3: Запуск приложения

```bash
python main.py
```

## Использование

### Быстрый старт:

1. **Первый запуск:**
   - Приложение автоматически проверит наличие зависимостей
   - Если Tor или X-Ray отсутствуют, будет предложено скачать их
   - Следуйте инструкциям мастера установки

2. **Настройка путей (если устанавливали вручную):**
   - Откройте вкладку "Настройки"
   - Укажите пути к `tor.exe` и `xray.exe`
   - Нажмите "Сохранить настройки"

3. **Добавление сервера:**
   - Скопируйте ссылку на сервер (vmess://, vless://, и т.д.)
   - Перейдите во вкладку "Серверы"
   - Нажмите "Импорт из буфера обмена"
   - Или добавьте сервер вручную

4. **Подключение:**
   - Выберите сервер из списка
   - На панели управления нажмите "Запустить X-Ray"
   - Для Tor просто нажмите "Запустить Tor"

5. **Настройка прокси:**
   - **SOCKS5 режим:** Приложения могут использовать прокси 127.0.0.1:10808
   - **Системный режим:** Весь трафик системы идет через прокси
   - **Проксирование приложений:** Запустите приложение через кнопку "Запустить с прокси"

Для создания standalone приложения:

- Поддержка современных методов шифрования
- Reality протокол для защиты от обнаружения

## Решение проблем

### Tor не запускается:
- Проверьте путь к tor.exe
- Убедитесь, что порт 9150 не занят
- Запустите от имени администратора

### X-Ray не подключается:
- Проверьте правильность конфигурации сервера
- Убедитесь, что сервер доступен
- Проверьте логи в журнале событий

### Системный прокси не работает:
- Приложение требует прав администратора для изменения системных настроек
- Некоторые приложения могут игнорировать системный прокси
